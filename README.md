# 🎮 Mis Proyectos de Juegos + IA 🤖

¡Bienvenido a mi repositorio! 🚀

Este espacio está dedicado a recopilar mis **proyectos de videojuegos, experimentos y pruebas realizadas con ayuda de inteligencia artificial**. Aquí encontrarás diferentes ideas, prototipos y proyectos que voy creando mientras aprendo y experimento con el desarrollo de videojuegos.

## 🕹️ ¿Qué encontrarás aquí?

* 🎮 Proyectos y prototipos de videojuegos.
* 🤖 Experimentos utilizando IA para desarrollar juegos.
* 🧠 Sistemas, mecánicas y scripts generados o mejorados con ayuda de IA.
* 🌐 Proyectos web y juegos experimentales.
* 🎨 Pruebas de personajes, mapas, interfaces y sistemas.
* 🛠️ Experimentos con diferentes motores y herramientas.
* 💡 Ideas que pueden convertirse en futuros proyectos.

## 📺 Contenido para mi canal

Este repositorio está pensado principalmente como **material para mi canal**.

Los proyectos pueden ser utilizados para crear videos, demostraciones, experimentos y contenido relacionado con el desarrollo de videojuegos y la inteligencia artificial.

> ⚠️ Algunos proyectos pueden estar incompletos, contener errores o ser simplemente experimentos. No todo lo que aparece aquí está pensado como un juego terminado.

## 🤖 Juegos creados con IA

Una parte importante del contenido consiste en experimentar con la pregunta:

**¿Qué tan lejos puedo llegar creando un videojuego con ayuda de IA?**

La IA puede ayudarme con código, ideas, sistemas, mecánicas y solución de problemas, pero los proyectos se van construyendo, modificando y probando durante el desarrollo.

## 🔧 Tecnologías

Dependiendo del proyecto, puedo utilizar herramientas como:

* 🎮 Godot
* 🌐 HTML / CSS / JavaScript
* 🐍 Python
* ☕ Java
* 🧩 Otras herramientas y tecnologías experimentales

## 📌 Importante

Este repositorio es principalmente un **laboratorio de proyectos para mi contenido**. Algunos proyectos pueden cambiar completamente con el tiempo, quedar abandonados o convertirse en algo totalmente diferente.

Si encuentras algo interesante, puedes revisar el código y ver cómo fue construido.
